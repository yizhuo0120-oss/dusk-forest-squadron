暮林机战 · Windows 离线演示包

1. 将整个 ZIP 解压到一个文件夹，不要直接在压缩包里运行。
2. 双击 start-demo.cmd。
3. 浏览器会打开本机游戏页面。建议使用较新的 Chrome 或 Edge。
4. 点击“开启摄像头”，允许摄像头权限后即可使用双手操作。
5. 游玩时保留启动窗口，结束后关闭窗口即可停止本机服务。

这个包已经包含手势模型、识别运行文件、3D 库和场景模型。
无需联网下载模型，无需安装 Python 或 Node.js，不需要域名。
摄像头画面在本机处理。服务只监听本机，不对局域网或公网开放。

不要直接双击 m2/index.html；浏览器会限制 file:// 页面加载模块。
如果浏览器没有自动打开，请复制启动窗口中的 http://localhost:端口/m2/ 地址。
如果摄像头被占用，请关闭会议软件或其他使用摄像头的页面后重试。

本包用于面试现场屏幕共享或网络不稳定时的备用演示。
